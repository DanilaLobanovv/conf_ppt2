## Описание проекта

Этот скрипт на Python предназначен для анализа зависимостей пакетов из репозитория. Он считывает конфигурационный файл в формате YAML, проверяет его корректность, загружает информацию о пакете из указанного URL и выводит список его зависимостей.

#Требования

#Для работы скрипта необходимы следующие компоненты:

Python 3.x
Установленные библиотеки:

PyYAML
Установка зависимостей

bash
pip install PyYAML
Использование

#Синтаксис запуска

bash
python script.py <config_file.yaml>
Формат конфигурационного файла

# Конфигурационный файл должен быть в формате YAML и содержать следующие поля:

yaml
URL: string                    # Базовый URL репозитория пакетов
package-name: string           # Имя пакета для анализа
package-version: string        # Версия пакета
mode: integer                  # Режим работы (не используется в текущей версии)
ASCII-mode: integer            # Режим ASCII (не используется в текущей версии)
depth: integer                 # Глубина анализа (не используется в текущей версии)
package-filter-str: string     # Строка фильтрации пакетов (не используется в текущей версии)
Пример конфигурационного файла

yaml
URL: "https://registry.npmjs.org"
package-name: "react"
package-version: "18.2.0"
mode: 1
ASCII-mode: 0
depth: 2
package-filter-str: ""
Функциональность

# Проверка файла конфигурации:

Существование файла
Корректность формата YAML
Наличие и корректность всех обязательных полей
Валидация URL:

Проверка формата URL
Подтверждение наличия схемы и доменной части
Загрузка данных о пакете:

Формирование полного URL для запроса
Загрузка JSON-данных о пакете
Извлечение информации о зависимостях
Вывод результатов:

Отображение списка зависимостей в формате "имя: версия"
Обработка ошибок

# Скрипт включает обработку следующих ошибок:

Файл конфигурации не найден
Неверный формат YAML
Некорректный URL
Неправильные типы данных в полях конфигурации
Ошибки сетевого запроса
Пример вывода

text
loose-envify: ^1.1.0
object-assign: ^4.1.1
prop-types: ^15.8.1
